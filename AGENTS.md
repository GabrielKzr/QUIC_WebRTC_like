# Contexto para agentes

Este repositório é um protótipo em desenvolvimento para pesquisa de comunicação
P2P através de NAT, com CHOWNAT, tunelamento TCP sobre UDP e QUIC via OpenSSL.

Ao iniciar uma sessão, leia `docs/repository-context.md` e
`docs/memory/agent-notes.md`. Confira o código e o estado do Git antes de usar
essas notas: elas são um contexto inicial, não uma especificação definitiva.

Mantenha as memórias atualizadas quando houver descobertas ou decisões relevantes.
Separe fatos verificados, relatos do histórico e hipóteses. Registre como uma
verificação foi feita e não afirme que o túnel funciona apenas porque compilou.
Preserve alterações do usuário e evite transformar uma tarefa pontual em uma
refatoração ampla sem necessidade.
